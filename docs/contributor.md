# Contributing Membership

Contributing Members actively participate in collective value creation through sustained contributions while benefiting from enhanced rights and resource access.

**Note:** You must first be a [Community Member](./community) before applying to become a Contributing Member.

## Value Exchange
Contributing Members provide expertise, time, and active contributions in exchange for enhanced resource access, participation opportunities, and potential patronage allocations.

## Distinctive Rights
- All Community Member rights
- Enhanced access to Cooperative resources
- Participation in select collaborative projects
- Expanded voting rights
- Eligibility for patronage allocations
- Potential committee participation
