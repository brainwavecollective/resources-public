# AI Powered Trash & Recycling Automation

A robotics solution that uses YOLO inference model for trash detection and the SO101 LeRobot 3D-printed arm to automate trash collection and recycling processes.

![Shanjay](/img/shanjay2.jpeg)

## Technical Components

- **Detection**: YOLO (You Only Look Once) computer vision model for real-time waste identification
- **Manipulation**: SO101 3D-printed robotic arm from Hugging Face's open-source LeRobot platform
- **Purpose**: Automated waste sorting to improve recycling efficiency and reduce contamination

## How It Works

1. Camera captures workspace video
2. YOLO model identifies and classifies waste items
3. System calculates object coordinates
4. SO101 arm picks up and sorts items into appropriate bins

## Applications

- Recycling facility automation
- Smart waste management systems
- Educational robotics demonstrations
- Environmental sustainability initiatives
