Von Puppenstein is a talking robot by Daniel Ritchie that layers a speech interface, realtime voice synthesis, and a character profiling system on top of [LeRobot](/docs/references/projects/lerobot?utm_source=brainwavecollective.ai) for conversational demos, public engagement, exploration of voice pipelines, and rapid prototyping and experimentation with HRI.

The project is built on a custom designed physical platform for transport and display at public presentations. Features encapsulated power management, DAC & microphone, speakers and amplification, cooling, and custom Raspberry Pi system with hardware-integrated services for mode switching and live voice cloning.  A puppet was modified to be attached to and driven by a LeRobot SO-101 arm.  

Software pipeline clones participant voices, evaluates scene with [Google Gemini](https://gemini.google.com/?utm_source=brainwavecollective.ai), generates text based on a selectable profile, and replays syntheitc voice using text-to-speech from [Cartesia](https://cartesia.ai/?utm_source=brainwavecollective.ai).
